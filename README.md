# 📄 Currículo & Portfólio

Página web pessoal que funciona como **currículo** e **portfólio**, desenvolvida com **HTML** no frontend e **Java Spring Boot** no backend.

---

## 🚀 Sobre o Projeto

Este projeto é uma aplicação web que apresenta de forma moderna e responsiva:
- Informações profissionais (experiência, formação, habilidades)
- Projetos do portfólio
- Contato

O frontend é feito em HTML (com CSS/JS) e o backend é construído com **Spring Boot**, responsável por servir as páginas e, futuramente, gerenciar dados dinamicamente.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia       | Uso                          |
|------------------|------------------------------|
| **HTML5**        | Estrutura das páginas        |
| **CSS3**         | Estilização e responsividade |
| **JavaScript**   | Interatividade               |
| **Java 25+**     | Linguagem principal          |
| **Spring Boot**  | Backend e servidor           |
| **Maven**        | Gerenciamento de dependências |
